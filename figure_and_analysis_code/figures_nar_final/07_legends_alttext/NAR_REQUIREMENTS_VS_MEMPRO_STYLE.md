# NAR requirements versus MemPro choices

- Journal-facing constraints: 178 mm main-figure width, <=230 mm height, editable PDF/SVG, >=300 dpi PNG, no clipped text, and minimum 5 pt final text.
- MemPro choices: Arial, low-saturation colour-blind-aware palette, grey for unknown, colour for effect size and dots for BH-FDR significance.
- Statistical language: contributing database count is not called independent experiment count; lineage counts remain putative; disease-expression concordance is not causality.
