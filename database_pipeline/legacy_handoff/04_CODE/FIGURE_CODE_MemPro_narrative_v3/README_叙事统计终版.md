# MemPro V7.1.1：M1–M8 叙事统计终版

本套图按论文结果部分的顺序组织，不是八张互不相关的统计汇总。

1. **M1 数据整合**：回答多来源整合是否带来真实新增覆盖，以及哪些来源存在重叠。
2. **M2 蛋白注释空间**：回答 7,800 个正式膜蛋白如何在五轴交叉分类中形成可重复的功能邻域。
3. **M3 表达背景**：回答膜蛋白在正常组织中的 RNA 检出、共表达结构及 RNA–IHC 一致性。
4. **M4 疾病背景**：回答疾病本体、器官系统和正常组织表达之间是否存在超出随机期望的一致性。
5. **M5 化学空间**：回答小分子结构覆盖和生物学状态如何分布，并比较 ECFP4 与 PAGTN pilot 的表示差异。
6. **M6 互作与位点环境**：回答共享配体形成的多靶点网络，以及不同膜侧位点对应的配体物化环境。
7. **M7 证据结构**：回答证据类型如何组合、来源如何解析到实验谱系键，以及 BE 等级由什么模态构成。
8. **M8 转化准备度**：回答哪些蛋白同时具有生物学价值和结构准备度，以及 529,168 个正式 pair 的 G1–G4 缺口。

## 交付内容

- `01_figures/PNG`：汇报和快速审阅；约 6,000 px 宽，450 dpi 输出。
- `01_figures/SVG`：可编辑矢量版本。
- `01_figures/PDF`：投稿和排版优先使用的矢量版本。
- `02_panel_data`：每个面板直接使用的统计表和降维坐标。
- `03_reproducible_scripts`：统计与绘图代码；正式数据库仍保持只读。
- `04_QA`：八图格式、边界、编码和文字重叠检查，以及整套 contact sheet。
- `05_captions_and_sources`：中文图解、投稿式 caption 和面板来源表。

## 统一视觉与统计规范

- Arial 字体；正文深灰；使用低饱和度配色 `#7b95c6`、`#49c2d9`、`#a1d8e8`、`#67a583`、`#a2c986`、`#d0e2c0`、`#fded95`、`#ffc1a6`、`#f59c7c`、`#f47254`、`#c85e62`。
- 密集散点采用透明度与栅格化；热图根据数据类型使用连续或以零为中心的色图。
- 所有面板均标注数据来源、统计单位、关键参数和限制。
- M3 只把 HPA `mapped + measured` 记录纳入分母；RNA 与 IHC 分开，不把 RNA 直接称为蛋白表达。
- M4 使用本体来源的多标签器官映射，不再使用单一关键词强制归类。
- M5 中 PAGTN 仅为四项物化性质监督训练的 pilot，不宣称为通用预训练化学表示。
- M7 的数据库来源数不等同于独立实验数；谱系键类型单独展示。
- M8 的 G1–G4 是结构/位点准备度，不是互作真实性等级。
