# M0. Data-source versions, contributions and membrane-proteome benchmarks

This reference figure documents the exact source snapshots used by the current MemPro build and the information contributed by each source. Protein sources provide canonical identifiers, sequences, membrane topology, expression, localization and membrane-family context; structural sources provide PDB-chain mappings, biological assemblies, membrane orientation, ligands and residue-level contacts; interaction sources provide assay-level activity, affinity, mechanism and enzyme–compound evidence; disease sources provide curated disease annotations and target–disease evidence. The “identity anchor” column specifies the identifier or structure representation used during integration rather than assuming that names are unique.

The lower panel compares the MemPro membrane-evidence layers with current public reference counts. These quantities are deliberately presented as benchmarks rather than additive totals because their units and inclusion rules differ: HPA reports genes, UniProtKB queries report reviewed accessions with particular annotation features, and MemPro reports canonical protein records. MemPro class A denotes integral/transmembrane proteins, class B non-transmembrane proteins directly embedded in or covalently anchored to the membrane, and class C peripheral membrane-associated proteins. The default website layer includes E1–E2 records; E3 records remain candidates and E0 records remain excluded audit records.

In the V6.2 protein master table, the 10,997-row audit universe comprises 7,904 default high-confidence E1–E2 A/B/C proteins, 2,652 E3 candidates and 441 E0 excluded/audit records. Therefore, 10,997 must not be interpreted or reported as the number of confirmed human membrane proteins. The class-A default count (5,490) is the most directly comparable MemPro count to current transmembrane-proteome estimates, although differences in gene/accession units and membrane definitions remain.
