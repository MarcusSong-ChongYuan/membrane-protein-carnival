# Compound Scope and Identity Policy v1.0

## Core

A validated, defined, non-polymeric chemical structure. Ordinary drugs,
research ligands, lipids, carbohydrates, natural products and macrocycles
remain core when they have a valid small-molecule structure.

## Extended

Chemically defined but boundary entities: peptidic or peptide-mimetic
structures, oligosaccharides, inorganic entities, organometallic entities and
records explicitly retained outside the v4.1 core.

## Unresolved

A stable source record for which no validated standard structure could be
established. These records are not merged by name.

## Excluded

Proteins, antibodies, antibody–drug conjugates, oligonucleotides, genes,
cells, enzymes, undefined polymers or mixtures, and records excluded by the
audited v4.1 scope decision.

## Website default

Only core parent compounds contribute to the default protein–compound summary.
Extended entities remain searchable as an optional layer. Unresolved and
excluded records are audit-only.
