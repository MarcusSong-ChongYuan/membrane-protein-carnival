## 文件夹

1. `00_交接说明`：项目结构、数据目录、复现方法、来源版本、限制和授权说明。
2. `01_正式数据_V6.2`：完整冻结数据、manifest、SHA256 和验证报告。正式分析优先从这里读取。
3. `02_展示图表_V6.2`：M0–M8 主图、S1–S6 补充图；含 PNG、SVG、PDF、绘图数据、caption 和图形 QA。
4. `03_Docking名单_V6.2`：pilot、standard、full non-conflict 和 conflict-review 名单及验证报告。
5. `04_复现代码`：膜蛋白、V4 整合、小分子、证据扩增、V6.2、绘图和 docking 的脚本与配置快照。
6. `05_质量控制`：增量整合与 V6.2 冻结过程的关键 QA 记录。
7. `06_清单与哈希`：本交接包全文件清单、大小和 SHA256。

## 重要边界

- 这是完整的**冻结派生数据与代码交接包**，不是所有第三方原始数据库的再分发包。
- BRENDA、PDBbind 及其他第三方数据在公开再发布前必须逐项检查当期许可；本包用于内部协作。
- Docking 名单是优先级清单，不是已经完成 receptor/ligand preparation 的可直接提交作业包。
- E3、冲突、未映射和 review 表均为审计/复核层，不能与默认高置信发布层混算。
