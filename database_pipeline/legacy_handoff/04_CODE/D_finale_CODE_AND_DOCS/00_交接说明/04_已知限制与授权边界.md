# 已知限制与授权边界

## 1. 科学与数据限制

1. **膜蛋白确认层**：10,997 是审计总行数，不等于 10,997 个全部高置信膜蛋白。E3 和 E0 必须与 E1/E2 分层。
2. **功能本体**：`other_family_defined` 和 `unclassified` 仍较多。GO、InterPro/Pfam、Reactome、TCDB、GPCRdb/IUPHAR 的多轴功能补注尚未成为冻结 V6.2 的完整正式层。
3. **疾病本体**：MONDO/OMIM/Orphanet/EFO 的跨本体统一仍不完整；同名不同 ID 或不同粒度的疾病不能按名称强行合并。
4. **Isoform**：关系层以 canonical UniProt accession 为主，尚未建立完整 isoform 级关系层。
5. **复合物**：多蛋白复合物、非人蛋白或模糊基因名保留在复核层；不按名称强制映射。complex-context ambiguous 记录不进入默认发布关系。
6. **来源独立性**：当前 distinct source count 是数据库标签数，不是对每条证据都完成了原始论文/实验谱系去重。
7. **结构与组装**：PDB 非对称单元链数不等于生理亚基数；状态依赖或研究间不一致被保留为冲突/多状态记录。
8. **负证据**：未解析记录仍留在 unmapped review 表；正式负证据只包含可靠小分子外键。
9. **已批准药物**：approved 标志较保守且不代表全球所有监管地区的完整批准状态。
10. **Docking**：名单是优先级和工作量分层，不是结合预测结果；仍需 receptor/ligand preparation、网格定义、redocking 和方法验证。

## 2. 授权与再发布

- 本包用于项目成员之间的内部交接。
- 派生表包含来自多个第三方数据库的字段。公开网站、公共下载、论文补充数据或 API 上线前，需要逐来源复核最新许可、署名和可再分发字段。
- BRENDA 2026.1 和 PDBbind 数据尤其需要按取得数据时的协议复核。原始 PDBbind 下载包没有复制进本交接包。
- DrugBank 未纳入当前数据收集范围。
- 不要把本包整体直接公开上传到 GitHub、公共云盘或网站下载区，除非完成许可审核并按来源拆分可公开与内部数据。

## 3. 推荐交接动作

1. 队友先验证 SHA256；
2. 从只读副本工作，不修改冻结 release；
3. 新分析输出写入独立 `runs/` 或新版本目录；
4. 所有筛选条件记录到脚本和 QA JSON；
5. 公开发布前建立逐来源 license matrix。
