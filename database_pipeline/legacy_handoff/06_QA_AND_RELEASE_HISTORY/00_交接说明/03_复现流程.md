# 复现流程

## 1. 复现范围

本包可复现数据转换、身份整理、合并、质量控制、图形和 docking 名单生成逻辑。由于第三方许可和体积原因，没有复制所有原始数据库快照；从零完全重建时需要按 `05_SOURCE_VERSIONS.tsv` 重新取得对应版本。

脚本中有一部分保存了原机器绝对路径 `D:\7.22\...`。在新机器运行前应统一修改 `ROOT`、`RUN_ROOT` 或配置文件路径。正式 release 文件本身不需要修改。

## 2. 环境

- 推荐 Python 3.12；
- 绘图环境的精确包版本见 `04_复现代码/requirements_plotting_freeze.txt`；
- 主要依赖：pandas、NumPy、SciPy、matplotlib、seaborn、RDKit、openpyxl；
- 网络抓取脚本需要稳定网络、API 限速和检查点目录；
- 大表重建建议至少 32 GB RAM、150 GB 可用磁盘；只读分析冻结表所需资源明显更低。

## 3. 流程顺序

### A. 膜蛋白基线

1. `membrane_master_scripts/bootstrap_v5.py`
2. `build_v5_master.py`
3. `build_v51_preliminary_review.py`
4. `finalize_v51_review.py`
5. `build_v51_release.py`
6. `build_v52_evidence_tiers.py`
7. `fetch_uniprot_sequences_v53.py`
8. `build_v53_sequence_release.py`
9. 对应 `validate_*.py`

### B. V4 关系整合与小分子 V1

1. `v4_integration_scripts/`：构建膜蛋白—小分子关系基线；
2. `small_molecule_scripts/`：结构抓取、RDKit 标准化、ChEBI/ChEMBL/PubChem 映射、form/parent 和主表；
3. 每个阶段运行相应 inspect/validate/package 脚本。

### C. 增量来源与 V6.1

1. `initialize_incremental_run_v3.py`、`freeze_baseline_v2.py`；
2. PubChem、GPCRdb、PDBe 抓取脚本；
3. PDBbind、BRENDA 标准化脚本；
4. 各来源 `normalize_*`、`resolve_*`；
5. `build_v61_premerge_identity.py`；
6. canonical 身份、盐型/立体化学和跨来源去重；
7. `finalize_v61_release.py` 及 validation/freeze 脚本。

### D. V6.2

1. `download_hpa_v62.py`；
2. `build_expression_location_module_v2.py`；
3. `build_subunit_assembly_module_v2.py`；
4. `prepare_negative_identity_v62.py`；
5. `fetch_negative_pubchem_properties_v62.py`；
6. `resolve_negative_evidence_v62.py`；
7. `preflight_v62_qa.py`；
8. `finalize_v62_release.py`。

正式发布要求 preflight 和 validation 状态均为 PASS，且 blocking error 为 0。

### E. 图和 Docking

- 图：`profile_figure_inputs_v62.py` → `build_figures_m1_m4_v62.py` → `build_figures_m5_m8_v62.py` → `build_supplementary_figures_v62.py` → `build_source_version_figure_v62.py` → `validate_figure_package_v62.py`。
- Docking：`build_docking_hpc_shortlists_v62.py`，输出后检查 `DOCKING_HPC_SHORTLIST_V2_V62_VALIDATION.json`。

## 4. 最小复核

只验证本包而不重新抓取数据时：

1. 对照 `01_正式数据_V6.2/SHA256SUMS_v6_2.txt`；
2. 确认 `V62_VALIDATION_REPORT.json` 为 PASS；
3. 确认 docking 和 figure QA JSON 为 PASS；
4. 对照 `06_清单与哈希/FILE_MANIFEST_SHA256.tsv` 验证交接过程中没有文件损坏。
