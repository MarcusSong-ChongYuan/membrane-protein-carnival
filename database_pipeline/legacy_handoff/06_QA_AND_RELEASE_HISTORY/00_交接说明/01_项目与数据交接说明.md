# 项目与数据交接说明

## 1. 项目目标

MemPro 的目标是建立人类膜蛋白及其小分子互作证据数据库。当前数据模型包含四个核心模块：

1. 人类膜蛋白主表；
2. 蛋白—基因—疾病关系表；
3. 小分子—膜蛋白结合证据及结合位点表；
4. 小分子母体及盐型、立体化学、质子化形式层级表。

V6.2 在 V6.1 冻结版本上增量加入完整选定 HPA 25.1 表达/定位矩阵、UniProt/PDBe 亚基与生物学组装模块，以及经结构身份解析的 PubChem 负证据。

## 2. 膜蛋白分类与发布层

- A：严格整合膜蛋白，通常具有跨膜区或强结构/实验膜证据。
- B：非跨膜但直接嵌入膜，包括单层嵌入、膜内区和脂质锚定。
- C：外周膜相关蛋白，稳定结合膜或定位于膜附近。

证据等级：

- E1：直接实验、结构或强拓扑证据；
- E2：人工注释和多个较强、相互支持的证据；
- E3：可接受但确定性较低的候选证据，主要用于复核；
- E0：不满足正式纳入规则或已排除的审计记录。

默认网站/论文核心统计应使用 E1/E2 的 A/B/C 记录；E3 不删除，但必须明确标成候选层。

## 3. 化学身份规则

- canonical compound：去除可安全识别的盐/溶剂等 form 差异后，用于跨数据库对齐的母体身份。
- form：保留盐型、立体化学、同位素、质子化和电荷形式。
- 自动合并要求唯一结构身份，核心键为完整 InChIKey；仅名称相同不自动合并。
- 立体化学、盐型或电荷母体关系不确定时进入 review 层。

## 4. 证据规则

- 阳性证据和负证据分别保存。
- 负证据按 `target UniProt + canonical compound + PubChem AID + SID` 去重。
- 阳性与负性在蛋白—canonical 小分子层比较，冲突不静默覆盖。
- `independent_source_count` 实际表示“不同贡献数据库标签数”，不能解释成已完成原始实验谱系去重。
- 结合位点必须保留 PDB、链、配体和残基坐标体系；不同坐标体系不可直接混合。
